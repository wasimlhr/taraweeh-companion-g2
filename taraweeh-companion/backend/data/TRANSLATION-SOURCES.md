# Translation sources

The added editions are imported verbatim from [risan/quran-json](https://github.com/risan/quran-json), a CC BY-SA 4.0 dataset. Every edition retains its original publisher terms. See [the upstream license](https://github.com/risan/quran-json/blob/main/LICENSE.txt).

The catalog records each translator, source URL, edition version, publication permission, snapshot URL and full-font scan. Existing English, Urdu, French, Spanish, Indonesian, Turkish, Bengali, Chinese, Russian, Swedish and Uzbek editions are unchanged.

Source catalog retrieved 2026-10-13T00:58:45.416Z. Each new edition has all 114 Hafs chapters and 6,236 verses with matching verse IDs. Scripts and recitation numbering are not changed.

QuranEnc editions credit their translator and QuranEnc in the app's language details. Their publication terms are recorded verbatim in language-catalog.json. Source text is never machine-translated or edited. Unsupported glasses editions use an explicitly labelled English fallback; the phone retains the original text.

Download sources are pinned to the imported GitHub dataset commit, with the configured backend and source publisher as fallbacks. Packs are optional and cached; full tables are excluded from the EHPK.
