Manual Next/Back selections in Translate now remain visible on glasses while
the server listens for recitation. Previously the searching animation only
protected manually selected verses in Practice and overwrote Translate's verse.

including callbacks already queued before a selection.

Validation: 224 app/backend tests and five phone build tests passed. Regression
coverage checks Next and Back in all three modes, matching phone/glasses text,
and surviving several stale animation callbacks. Actual EvenHub simulator
captures verify both directions after waiting beyond the animation interval.
