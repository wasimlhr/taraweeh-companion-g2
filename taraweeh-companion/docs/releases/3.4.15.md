# v3.4.15

Glasses Settings offer Arabic only, translation only, transliteration only,
Arabic above translation, and translation with transliteration. The in-app
preview follows the selected layout.

Only Arabic is rasterized. Combined layouts use two Arabic image tiles above
a native translation container. Unsupported translation scripts retain the
existing English fallback; Cyrillic Uzbek retains its Latin conversion.
Long verses paginate without losing either text. Al-Baqarah 2:282 was checked
on the actual EvenHub simulator, with Uzbek native translation across seven
pages and captures of pages one and two. Physical-glasses verification remains
pending.

Validation: 221 app/backend tests and five phone build tests passed. EHPK uses
SDK 0.0.16 and requires Even App 2.2.10. Both Railway deployments must be checked
against this release's commit and live content before reporting deployment.
