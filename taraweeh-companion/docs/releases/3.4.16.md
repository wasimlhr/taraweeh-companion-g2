Follow pace now blocks predicted verse advancement and changes the displayed
ayah only on real recitation confirmation. Fast and Slow keep their existing
pace estimates; frontend page timing no longer subtracts a provider-specific
offset. Translate remains global Quran matching while Practice may restrict
matching to the selected surah. Follow does not enable Practice mode.

Hold/Resume is beside the pace control, below the existing mode controls.
The glasses mode/count box uses six-pixel padding and measured text centering.

Validation: 223 app/backend tests and five phone build tests passed. New tests
cover no timer advancement, no advancement on noise, real-match advancement,
and independent Follow/Fast/Slow selections. Real EvenHub simulator captures
verify the centered mode box and relocated controls using controlled verse
input. Live microphone recognition and physical-glasses acceptance are separate.
